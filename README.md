# Netflix EDA Project

## Problem Statement
The objective of this project is to perform Exploratory Data Analysis (EDA) on the Netflix dataset to identify trends, patterns, and insights related to Netflix content.

## Dataset Details
Dataset Source: Kaggle Netflix Dataset

Dataset includes:
- Movies and TV Shows
- Release Year
- Ratings
- Country
- Genres
- Date Added

## Tools and Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Approach
The following steps were performed in this project:

1. Data Loading
2. Data Cleaning
3. Handling Missing Values
4. Exploratory Data Analysis
5. Data Visualization
6. Trend Identification
7. Insight Generation

## Analysis Performed
- Movies vs TV Shows Analysis
- Top Contributing Countries
- Ratings Distribution
- Genre Analysis
- Content Growth Over Years
- Correlation Analysis

## Final Insights
1. Netflix has a significantly higher number of Movies compared to TV Shows.

2. The United States contributes the largest share of content available on Netflix.

3. Netflix content additions increased rapidly after 2015, showing major platform growth.

4. TV-MA is the most common content rating, indicating a strong focus on mature audiences.

5. Drama and International Movies are among the most popular genres on the platform.

## Outcome
This project helped in understanding:
- Data Cleaning Techniques
- Exploratory Data Analysis (EDA)
- Data Visualization
- Trend Analysis
- Business Insights Generation
